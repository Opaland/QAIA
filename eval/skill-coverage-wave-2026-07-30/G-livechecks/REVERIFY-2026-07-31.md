## New finding from this pass — `probe-mask-bbox.js` is not stable

`visual-check/RESULTS.md` cites `textWidthDelta = -1.5625` as the measured root cause of the
20-px masked diff. Three consecutive runs of the same probe today:

```
run A:  before textW 463.484375   after textW 463.453125   textWidthDelta -0.03125
run B:  before textW 463.484375   after textW 468.78125    textWidthDelta  5.296875
run C:  before textW 470.34375    after textW 468.78125    textWidthDelta -1.5625
```

The probe does not wait for the webfont to finish loading, so `before` is sometimes measured with
the fallback font. **The mechanism still holds** (a text node's bbox width is a function of its
text, so Playwright's bbox-shaped mask moves when the text changes) and the *consequence* — the
masked snapshot diffing by 20 px instead of 0 — reproduced exactly, twice. But the specific figure
`-1.5625` should not be quoted as a stable measurement; the honest statement is "the box width
changes by roughly 0–5 px depending on the loaded font".

This weakens the *evidence line* of suspected defect #1, not its *conclusion*.
